Staff: start a shift, orders, corrections, private QR access, payments, receipts, reports and handover. Guests: open a tab, optional ordering, photos, payment, emailing and expiry. Administrators: install, configure, manage roles/profiles/catalogs, import CSV, configure mail/notices, back up and restore.

Personal: Schichtbeginn, Bestellung, Korrekturen, privater QR-Zugang, Zahlungen, Belege, Berichte und Übergabe. Gäste: Bonzugriff, optionale Bestellung, Fotos, Zahlung, E-Mail und Ablauf. Administration: Installation, Einstellungen, Rollen/Profile/Sortiment, CSV-Import, Mail/Hinweise, Sicherung und Wiederherstellung.

Use your association's APOS address for actual operations; the public project website is informational. / Verwenden Sie für den Betrieb die APOS-Adresse Ihres Vereins; die öffentliche Projektwebsite dient der Information.
