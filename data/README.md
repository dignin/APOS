# Diceware word list attribution

`eff_large_wordlist.txt` is the unmodified EFF Large Wordlist, created by
Joseph Bonneau for the Electronic Frontier Foundation (2016).

Source: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt
Background: https://www.eff.org/dice
License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/
EFF copyright policy: https://www.eff.org/copyright

Downloaded 3 October 2026. APOS selects four words independently and uniformly
with Python's cryptographic random generator. The list is bundled so code
generation needs no network connection. English words are used in both interface
languages so each guest code remains stable when switching language.
